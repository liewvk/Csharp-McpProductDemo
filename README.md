# McpProductDemo

A simple C# console application demo for the MCP product sample described in the repository's chapter context.

## Overview

This repository contains a minimal .NET 10 console project used as a starting point for experimenting with AI agent and model-context-pattern concepts in C#.

## Project structure

- `Program.cs` - entry point for the application
- `McpProductDemo.csproj` - .NET project configuration
- `McpProductDemo.slnx` - solution file for the project

## Prerequisites

- .NET 10 SDK or newer
- A compatible development environment such as Visual Studio, VS Code, or the .NET CLI

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/liewvk/Csharp-McpProductDemo.git
   cd Csharp-McpProductDemo
   ```
2. Restore dependencies:
   ```bash
   dotnet restore
   ```
3. Build the project:
   ```bash
   dotnet build
   ```
4. Run the application:
   ```bash
   dotnet run
   ```

## Current sample behavior

The default program prints:

```text
Hello, World!
```

This project is intentionally simple and can be used as a foundation for extending the demo with additional AI agent or MCP-related functionality.
